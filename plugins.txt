# Third-party Moodle plugins baked into both images at build time.
#
# One plugin per line:   <directory under public/>   <source>
#
#   directory  where the plugin lives in Moodle 5.1+, e.g. theme/<name>,
#              mod/<name>, blocks/<name>, local/<name>, admin/tool/<name>,
#              course/format/<name>, question/type/<name>
#   source     a ZIP download URL (moodle.org "Download" link, or a GitHub
#              https://github.com/<owner>/<repo>/releases/download/<tag>/<file>.zip),
#              or <git-url>.git@<tag|branch|commit>
#
# After a rebuild, deploy and run admin/cli/upgrade.php to install the plugins
# (see README). To remove one, uninstall it in Moodle first, then drop the line.
#
# Examples:
#   theme/boost_union   https://moodle.org/plugins/download.php/<id>/theme_boost_union_moodle50_<build>.zip
#   mod/attendance      https://github.com/danmarsden/moodle-mod_attendance.git@<tag>
